### 2.4 本轮并行审计新增发现

1. API 上传对象目前使用可覆盖写入：同一有效上传凭据在 `complete` 前重复 PUT 会替换首次字节。现有测试只覆盖了 `complete` 后重放，尚未覆盖完成前覆盖。该问题必须改为原子“仅首次创建”，重复 PUT 返回稳定 `409 UPLOAD_ALREADY_RECEIVED`，并验证首次字节保持不变。
2. Web 移动端 `.letter-body` 会降到 `18px`，低于项目已经定义的长辈正文默认 `20px` 门槛。
3. 小程序素材删除目前立即执行，缺确认或撤销；意图/编辑页部分输入控件缺 `aria-label`，分段控件缺 `aria-pressed`；3 个次要按钮高度为 `72-80rpx`，低于 `88rpx` 目标。
4. 上述 Web/小程序问题均来自代码审计，尚未完成微信开发者工具、系统大字号、读屏和真机点击验证，不能据此关闭 `FIX-023`。
