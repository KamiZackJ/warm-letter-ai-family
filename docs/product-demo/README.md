# 暖笺互动产品演示

主入口是仓库根目录的 [`暖笺_互动产品演示.html`](../../暖笺_互动产品演示.html)。双击即可离线打开，无需启动 API、H5 或小程序。

这不是材料目录，而是一条可操作的产品旅程：

1. 选择脱敏的照片、语音和文字素材。
2. 生成带 `sourceRefs` 的本地草稿。
3. 编辑段落，观察归因转为“修改后待核对依据”。
4. 重新核对素材或标记“本人补充”，再确认寄出。
5. 在收信端切换字号、展开来源、触发本地系统朗读、发送本地回复。

## 展示口径

- 页面使用固定的 `case_001` 脱敏事实，不含原始照片或语音。
- 页面模拟本地 Fake AI 和本地状态，不会请求真实 OpenAI，也不会产生真实分享链接。
- 工程依据抽屉定位到现有小程序、API 和 H5 的实现。真实 AI、微信双真机、生产部署与真人用户测试仍未完成，不能表述为已上线能力。

## 便携打包

若只演示产品交互，压缩包至少保留：

```text
暖笺_互动产品演示.html
产品演示/index.html
evidence/2026-08-15/h5-1440x900.png
```

三个路径均为相对路径。第二部分的真实素材页和材料包应单独作为受控“证据附件包”发送，不应与本互动页混作同一个主展示入口。
