# 小程序 0.2.3：超时恢复、气泡引导与用户文案

日期：2026-09-19（Asia/Shanghai）。代码提交：`ff5f8a379d09a952a3be9a33d481b3e186697f86`。已推送 GitHub、部署后端，并在微信后台核实为当前体验版；未提交正式审核或发布。

## 本轮变化

- 新用户第一次打开首页即可看到依附真实控件的三步小气泡：写家书入口、最近家书、使用指南。每步可跳过；跳过只关闭提示，不创建家书。完成或跳过后本机记住，首页“使用指南”可重看；可以随时点击写信，无需看完引导。
- 气泡沿用纸色与深绿，带指向控件的小箭头，正文 18px、操作按钮至少 44px，无全屏遮罩、自动播放或过渡动画。实际模拟器检查后修正了微信默认按钮样式导致的纵向堆叠。
- 六个页面移除开发/演示环境横幅，首页和素材页移除合成演示入口；登录、上传、分享等错误改为易懂中文。AI 辅助整理、AI 合成声音、主动选择素材及内容核对说明保留；后端环境校验和正式环境门禁仍生效。
- 有本机家书记录或待生成任务的老用户不自动进入指南。首次展示不等待网络；迟到的历史记录不会打断用户已经开始的指南操作。没有自动索取权限、调用 AI 或填入素材。
- 家书生成增加覆盖媒体读取、转写、写作及事实复核的统一等待上限；迟到结果不能再写入草稿或启动下一阶段。保留原有事实复核与预算内的重试。
- 朗读生成请求、完整响应流和供应商音频下载共用一个等待上限；到期中止并报告可重试错误，不接受部分音频。
- 小程序给网络请求、文件读取、微信登录和朗读文件写入补上回调丢失时的结束机制。失败后解除忙碌状态，晚到结果不覆盖当前操作；失败的临时音频会清理。
- 预览页防止朗读、换稿和确认同时发起。切到后台停止播放，后台完成朗读不会自动播放；离开页面后晚到的试听文件会清理。旧加载响应不能覆盖较新的预览。
- 更换音色后，需要生成成功或选择“暂不更换声音”再确认；试听标明实际声音，避免预览选择与寄出朗读不一致。若请求失败导致保存结果未知，不假定旧音色仍是当前版本。
- 客户端未读到结果时保留“回首页查看结果”按钮，不误称后台一定仍在生成；页面标题、步骤与说明按独立行排列。

## 等待上限不等于生成速度

| 范围 | 本轮代码默认或沿用配置 | 含义 |
| --- | --- | --- |
| OpenAI-compatible 整次家书生成 | 新增 `OPENAI_COMPATIBLE_GENERATION_TIMEOUT_MS=150000` 默认值 | 从提供者读取媒体开始计算，覆盖转写、写作、复核及其重试；不包含此前用户上传或登录 |
| 单段流式语音转写 | 沿用 `OPENAI_COMPATIBLE_TIMEOUT_MS`，上一部署为 60000 | 单段上限与整次生成剩余预算同时约束；收到片段不重新计时 |
| 正常结束但空结果的限定补试 | 最多 30000，且受整次剩余预算约束 | 不增加一份独立的完整生成预算 |
| Qwen / Doubao 朗读提供者 | 沿用各自超时配置，默认 120000 | 合成请求与供应商音频下载共用预算，不覆盖其后对象存储写入 |
| 小程序普通请求、媒体读取 | 使用环境请求上限，当前体验配置 12000 | 单次操作的等待保护；登录、健康检查等步骤可能依次发生 |
| 小程序微信登录 / 朗读文件写入 | 各 12000 | 回调未返回也能结束当前等待，允许重新操作 |
| 小程序朗读请求 / 前台生成轮询 | 分别 130000 / 180000 | 客户端不无限等待；轮询到期本身不能证明服务端已成功、失败或仍在运行 |

这些改动用于限制异常等待和恢复操作，**没有本轮正常生成更快的实测结论**。此前关闭 Qwen 额外思考的 60–75 秒样本仍只是单次对照，不是整封家书的时限承诺。本轮没有调用付费 AI 做新的速度测量。

## 接下来怎样复测

1. 重新打开体验版；老用户可点首页“使用指南”，检查下一步、跳过、知道了，确认跳过不会进入新建流程。
2. 创建新家书，添加自己的照片、录音或文字，完成生成、核对与改稿。
3. 生成朗读后切换音色：确认按钮应等待处理；生成新声音或“暂不更换声音”后可继续。切到后台不自动播放，返回可手动试听。
4. 让另一位已加入体验成员的队友打开分享并阅读、播放、回复。真机断网和恢复路径仍需记录。
