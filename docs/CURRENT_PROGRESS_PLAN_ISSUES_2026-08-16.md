## 5. 当前问题与风险

### 代码与验证

- 工作树混合多条工作流且差异较大；必须分批审查、显式暂存文件并独立提交。
- 素材端到端幂等已通过本地测试但尚未完成独立审查；当前内存仓储无法提供跨进程重启或多实例的持久幂等保证。
- 素材页远端失败后若用户修改文字，当前仍复用原 Material ID，服务端会按不可变请求指纹设计返回 `409`；页面需要为改稿生成新 ID，或明确保留原稿只允许原样重试。
- API 回复幂等重放顺序尚未收口，合法重试可能被限流或安全服务故障阻断。
- H5 多处辅助文字仍为 `11-13px`，不满足当前“来源/辅助文字至少 14px”的适老目标；真实 Playwright 证据也尚未固化。
- Web 未保存回复草稿缺少离开/刷新保护，用户可能误丢输入。
- 小程序 `ensureLogin()` 只检查本地 token 是否存在，业务请求收到 `401 UNAUTHORIZED` 后不会重新登录；API 重启会使旧开发 token 永久失效，用户目前只能清理本地存储恢复。这会继续阻止 `G1` 可重复演示。
- 当前新增代码尚未进入远端 CI；本地通过不能替代提交后两条远端 `verify`。
- “重新生成”并发保护、完整历史家书入口和跨设备历史/署名仍是独立 P1，不能被当前恢复批次顺带视为完成。
- `PROJECT_STATUS.md`、`ACCEPTANCE_CHECKLIST.md` 等旧文档仍可能引用旧 HEAD 或旧 CI；完成当前批次前以本文件的“已发布基线”口径为准。

### 外部门禁

- 缺真实 OpenAI 凭据、模型权限、额度、授权四素材和人工事实基准。
- 缺正式微信 AppID、可达 HTTPS API、体验成员、开发者工具/双真机证据。
- 正式内容审核、完整删除、生产持久化、共享限流、监控和备份策略未闭环。
- 参赛资格、目标期次、学校截止、快手账号、小程序主体、视频、PDF 和报名回执尚未完整归档。
