## 构建与核验链路

1. 构建脚本读取队友提供的三项主来源，并固定校验照片、语音和三版文本的 SHA-256。
2. 脚本执行物理照片裁切，复制允许受控展示的 m4a 和五份审计证据。
3. 离线包页面通过相邻的 `demo-case.js` 装载 A/B/C 固定审核稿、相对媒体路径与 T01-T07；React 阅读页则在启动时校验并读取同一受控包的 `demo-case.json`，仅呈现推荐 A，不再维护独立正文副本。
4. 长图脚本从同一受控 CASE-001 读取推荐 A、裁切图和披露语，生成 PNG 与独立核验清单。
5. 最终 ZIP 仅使用相对路径。解压到另一台电脑后，双击 `index.html` 即可演示；不得改写为绝对盘符路径。

构建命令、文件清单和防泄漏门禁见 [`CONTROLLED_CASE_DEMO.md`](./CONTROLLED_CASE_DEMO.md)。本机所有 staging、长图和 ZIP 都必须保留在 `D:\tmp\warm-letter-ai-family`；仓库中不保存原始照片、语音或来源路径。
