# 可搬家压缩包布局

压缩包不依赖 GitHub、不依赖 C 盘绝对路径。解压后从根目录双击 `暖笺_阶段成果展示.html`。

```text
暖笺_阶段成果展示包/
├─ 暖笺_阶段成果展示.html       # 唯一入口，跳转到展示中心/index.html
├─ 展示中心/
│  ├─ index.html                 # 阶段成果展示中心
│  └─ README.md                  # 展示顺序和本地交互说明
├─ 内容成果/
│  ├─ 暖笺_真实素材家书展示.html  # 自包含真实照片/语音/三版家书展示页
│  ├─ 暖笺_真人用户测试工具.html
│  └─ 完整成果包/                 # 第二部分原始交付结构
│     ├─ README.md
│     ├─ 与第一位同学融合说明.md
│     ├─ 素材/                     # 生活照片、语音
│     ├─ 成品/
│     ├─ 展示/
│     ├─ 测试/
│     ├─ 接口/
│     ├─ 规则/
│     ├─ 核验/
│     └─ 配套文件/
├─ 证据/
│  └─ h5-1440x900.png
└─ 文档/
   ├─ PHASE_DELIVERY_REPORT_2026-08-25.md
   ├─ INTERNAL_DEMO_RUNBOOK_2026-08-25.md
   ├─ PROJECT_STATUS.md
   └─ CASE_001_SAFE_SNAPSHOT.md
```

展示中心中的“真实素材展示页路径”默认是：

```text
../内容成果/暖笺_真实素材家书展示.html
```

这个路径相对于 `展示中心/index.html`，换电脑或换盘符都不需要修改。压缩包中的照片和语音仅用于队内受控展示，不应再次上传到公开仓库或公开网盘。
