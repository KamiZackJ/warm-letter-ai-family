# 暖笺阶段成果展示中心

这是给队友、项目经理和内部评审使用的现场展示首页，不替代 GitHub 仓库，也不伪装成生产环境。

需要发给同学时，按 [`PORTABLE_BUNDLE_LAYOUT.md`](./PORTABLE_BUNDLE_LAYOUT.md) 的结构组包；不要把本机 `C:\Users\...` 路径写进压缩包。

## 最快打开

双击本目录中的 `index.html`。第一屏先讲产品价值，随后按真实内容、安全边界、产品闭环和下一阶段推进展开。

页面不再保存任何人的本机素材路径。当前主演示应使用受控融合产品包：配置、裁切照片和语音全部放在入口旁的相对路径中；仓库首页提供 `http://127.0.0.1:4183/` 直达按钮（本机已启动静态服务时），也保留一个可选的受控包入口字段，便于从不同电脑打开解压后的 `index.html`。

展示中心首屏的 CASE-001 核验卡会在 `4183` 已启动时直接加载队友照片裁切图和原始语音播放器；连接不可用时只显示“受控照片预览未连接”的提示，不会用合成图片或合成语音填充。要展示真实素材，优先打开 `4183` 或 ZIP 根目录 `index.html`。

## 推荐现场顺序

1. 打开受控融合产品包 `index.html`：用 1 分钟说明暖笺解决什么问题，以及当前是 G0 阶段；不要把历史合成截图当作当前成果。
2. 在同一页面查看物理裁切照片、播放原始 m4a，并比较 A/B/C 三版固定审核稿。
3. 选择一版，演示编辑后来源待核对、确认快照、收信端字号/来源/原音和回复。
4. 展开“融合依据”，说明哪些来自队友、哪些由本仓库工程承接，以及哪些外部门禁仍未完成。
5. 只有评审追问原始接口、规则或工作簿时，才打开单独保管的证据附件包。

本机联调时可直接打开 `http://127.0.0.1:4183/` 查看已装入队友真实照片裁切图、原始 m4a 和 A/B/C；`http://127.0.0.1:4173/` 是同一 CASE-001 的 React H5 阅读端。若端口未启动，直接解压并双击受控 ZIP 根目录 `index.html`。

## 构建受控融合包

在仓库根目录打开 PowerShell，`SourceRoot` 指向队友成果包的内层根目录：

```powershell
$sourceRoot = '<队友成果包内层根目录>'
powershell -ExecutionPolicy Bypass -File .\scripts\create-controlled-case-demo.ps1 `
  -SourceRoot $sourceRoot `
  -OutputRoot 'D:\tmp\warm-letter-ai-family\controlled-case-001'
```

脚本输出可搬家的目录和同级 ZIP。解压后直接双击根目录 `index.html`；如需浏览器自动化复验，可从该目录启动本地静态服务器。
