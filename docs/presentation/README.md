# 暖笺阶段成果展示中心

这是给队友、项目经理和内部评审使用的现场展示首页，不替代 GitHub 仓库，也不伪装成生产环境。

## 最快打开

双击本目录中的 `index.html`。第一屏先讲产品价值，随后按真实内容、安全边界、产品闭环和下一阶段推进展开。

页面中的“打开真实素材页”按钮默认指向当前机器的微信辅助材料路径。如果换电脑，直接在页面底部编辑路径即可；标准内层成果包中的对应文件是 `展示/暖笺_真实素材家书展示.html`。

## 推荐现场顺序

1. 展示中心首页：用 1 分钟说明暖笺解决什么问题，以及当前是 G0 阶段。
2. 点击“打开真实素材页”：用 3 分钟展示照片、语音、三版家书、事实映射和 T01-T07。
3. 回到展示中心，点击“打开 H5”：用 2-3 分钟展示大字阅读、来源、音频和回复。
4. 需要证明后端闭环时，点击“复制命令”，在仓库根目录执行 API demo。
5. 最后打开阶段报告，只讲已完成证据、明确缺口和下一阶段前三项。

## 本地 H5 交互

在仓库根目录打开 PowerShell：

```powershell
$env:TEMP='D:\tmp\warm-letter-ai-family'
$env:TMP='D:\tmp\warm-letter-ai-family'
pnpm dev:api
pnpm dev:web
```

然后在展示中心点击“打开 H5”，或访问 `http://127.0.0.1:4173/`。
