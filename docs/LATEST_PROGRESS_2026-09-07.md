## 尚未完成和风险

1. GitHub Pages 是静态托管，当前没有可安全保存供应商密钥的公网 API；DeepSeek 和豆包语音不能仅靠 Pages 上线。
2. DeepSeek 模式只处理用户填写的文字，不读取照片、截图或语音；照片在个性创作页只做本地预览。
3. 比赛和生产模式当前仍要求 `AI_PROVIDER=openai`。若要改变供应商策略，需要单独评审比赛口径、测试和运行配置，不能直接改环境变量绕过门禁。
4. 真实供应商调用、费用与配额、HTTPS 后端、正式鉴权、持久化、跨实例限流和内容审核尚无端到端上线证据。
5. 快手/iCAN 的实际发布、团队字段和成功回执仍需负责人本人登录完成，并存入私密交接记录。
