## 5. 当前问题与责任边界

### P0 外部阻塞

- 没有真实 OpenAI 凭据、模型权限、额度和可用网络，不能把 Fake AI 或本地自动化当成 AI 核心证据。
- 没有正式微信 AppID、`code2Session`、可达 HTTPS API、体验成员和两台设备，不能把 H5 或模拟器当成小程序双设备闭环。
- 正式审核、完整删除和生产持久化尚未落地，因此不能公测或生产发布。
- 参赛资格、目标期次、学校截止、快手账号和小程序主体证据尚未归档，不能冻结比赛提交材料。

### P1 代码与产品风险

- FIX-026 本地实现、故障注入和最新远端 CI 已通过；剩余风险是活动进程长期卡住时带 owner 的 stage 会保留，以及当前文件系统适配器仍没有生产级生命周期、跨实例监控和共享存储保证。
- H5 三档字号控制和小程序关键异常恢复已经在本地实现，但尚未完成全部独立复核、全量门禁、提交、推送和远端 CI，因此仍不能标记为已交付。
- `realApi.listLetters()` 当前会捕获所有单封取信错误并返回 `null`；网络、鉴权或 5xx 仍可能被伪装成“没有家书”，首页的持久错误页面尚未在真实 API 链路闭环。
- 素材页当前只有一个动作重试上下文；图片批量上传或远端成功后本地 ID 持久化失败时，仍缺少明确的分阶段状态、幂等重试和孤儿素材处理，连续不同动作失败也可能覆盖待重试上下文。
- “重新生成”并发保护和完整历史家书入口仍未完成。
- 小程序异常恢复的自动化检查不能替代微信开发者工具与真机验证；图片、音频、卸载清理、删除失败和回复重发仍需运行态取证。
- 长图、短片目前只有计划/契约层描述，尚无可交付成品证据。
- 既有状态文档仍可能存在旧提交号和旧 CI 描述；本文件是当前快照，完成全量同步前不得把其他旧文档单独当成最新状态。
