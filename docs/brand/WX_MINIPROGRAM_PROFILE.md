# 暖笺小程序资料

## 推荐名称

暖笺

名称是否可用以微信公众平台实时校验为准；不要在名称中加入未经备案的品牌、机构或平台名称。

## 推荐简介

### 短版（优先用于后台简介）

把今天写给想念的人：用照片、语音和文字生成可编辑的温柔家书，与家人分享并回复。

### 完整版（审核材料或介绍页）

暖笺是一款面向家庭沟通的 AI 家书工具。选择照片、语音或文字，生成可编辑、可核对来源的家书草稿；确认后分享给家人阅读、播放语音并回复。
