# 暖笺快手与 iCAN 提交文案

## 作品名称

暖笺：基于生活素材与来源核对的 AI 家书

## 作品简介

暖笺面向异地生活与家庭沟通，将用户主动选择的照片、语音和文字整理为可编辑家书。系统提供三种表达版本，并为段落保留素材来源；用户修改后需重新核对，确认后再交给家人阅读与回复。项目已完成 H5、微信小程序、API 与共享契约骨架，公开提供脱敏体验，并以受控固定案例验证隐私裁切、内容安全和离线移交。

## 快手发布正文

异地生活里，我们有很多照片、语音和零碎感受，却常常只对家里说一句“我挺好的”。暖笺让用户主动选择素材，整理为三种表达版本；每段文字保留来源，编辑后必须重新核对，本人确认后再交给家人阅读与回复。

当前公开演示使用团队提供并人工审核的固定案例，不在现场实时调用模型；公开版不含真实照片、语音、原始转写或凭据。项目已完成 H5、微信小程序、Fastify API 与共享契约骨架，自动化基线 355/355。
