# 暖笺 3 分钟评审演示讲稿

## 演示前

- 首选入口：根目录 `START_HERE.html`，再点击“开始操作演示”。
- 直达入口：`../interactive/index.html`。
- 公开备用入口：<https://kamizackj.github.io/warm-letter-ai-family/>。
- 关闭无关通知，浏览器缩放保持 100%，提前确认离线照片、音频和 A/B/C 可以加载。
- 不需要启动 API，也不要现场修改受控素材文件。

## 0:00-0:20 问题与产品

讲述：

> 异地生活的人每天都有照片、语音和零碎文字，却常常只发出一句“我挺好的”。暖笺让用户主动选择这些生活素材，AI 帮助组织成可核对的家书草稿，本人确认后家人才会收到。

页面动作：指向“素材 -> 三版比较 -> 来源核对 -> 确认 -> 阅读/回复”的旅程条。

## 0:20-1:10 真实材料进入产品

页面动作：

1. 展示物理裁切照片和原始示例语音。
2. 选择素材并生成草稿。
3. 快速切换 A、B、C 三版。

讲述：

> 这三版来自队友固定审核稿，不冒充实时模型输出。照片只保留货架、商品和价签，不保留右侧无关人物；语音只用于原音播放和已审核事实映射。

## 1:10-1:50 来源核对与确认

页面动作：

1. 修改一段文字。
2. 展示“修改后待核对依据”。
3. 重新选择来源或标记为本人补充。
4. 确认当前版本。

讲述：

> 暖笺的 AI 价值不只是代写。每段内容都要能回到用户主动选择的素材；一旦编辑，旧来源不会自动沿用，必须重新核对。确认后正文和署名被冻结为收信端快照。

## 1:50-2:25 家人阅读与回复

页面动作：

1. 进入阅读端。
2. 切换标准、大字、特大字号。
3. 展开段落来源。
4. 播放原始语音。
5. 输入一句回复并发送。

讲述：

> 收信人不需要安装应用。页面支持大字阅读、查看来源、播放原音和回复。当前演示中的回复保存在本页；正式服务的短期凭据、撤销、限流和幂等已有工程实现。

## 2:25-2:50 安全与工程证据

页面动作：打开“工程依据”。

讲述：

> 固定案例的 T01-T07 全部通过。程序禁止从照片推断购买、食用、功效或人物身份。仓库目前有小程序、Fastify API、React H5 和共享契约，自动化基线是 355/355。

## 2:50-3:00 收口

讲述：

> 暖笺已经证明，真实生活素材可以在隐私边界内进入一条完整的家书产品闭环。下一阶段是补齐真实 OpenAI、微信双设备和真人测试证据。

## 失败备用

- 受控媒体无法播放：继续演示 A/B/C、来源复核、确认、字号和回复，并说明媒体只在授权包中存在。
- 离线页面无法打开：立即切换公开脱敏入口。
- 网络不可用：继续使用解压后的离线 `interactive/index.html`。
- 不现场承诺未完成的真实 OpenAI、微信双真机或生产能力。
