### P1 技术与产品风险

1. 当前任务、仓储和限流仍是单进程实现；生产需要 PostgreSQL/Redis、持久队列、跨实例原子约束和可信代理。
2. 跨端请求/响应仍有私有 DTO，`FIX-012` 尚未关闭；新生成任务边界已使用共享 schema，但还未覆盖全部 API。
3. OpenAI 输出尚未细分 refusal 与 incomplete，也未设置生成输出 token 预算和完整 usage/latency 指标。
4. 音频格式范围、中文专名提示和关键词评测需要与真实转写模型再对齐。
5. H5 和小程序已补焦点、热区、ARIA 与适老字号基础，但仍缺微信真机读屏、系统大字号、200% 缩放和最长中文文案验收。
6. W1 本地代码门禁已经绑定提交 SHA，但远端 GitHub Actions 尚未运行；本地门禁通过不等于远端 CI、G2 或发布通过。
