# 暖笺微信小程序

原生微信小程序。当前代码为 1.0.0 正式候选版本，开发版、体验版和正式版均要求连接生产 API；只有显式测试配置允许本地 mock。正式后端已恢复，1.0.0 已上传为体验版，尚未提审或正式发布，实际进度见[正式发布记录](../../docs/PRODUCTION_RELEASE_1_0_0_2026-09-23.md)。

## 运行

1. 打开微信开发者工具，选择“导入项目”。
2. 项目目录选择本目录 `apps/miniprogram`。
3. `project.config.json` 已配置项目 AppID `wx281b5275e4a1601f`；接手人若使用其他小程序，须在本地替换为自己的 AppID。
4. 编译后从首页选择“写一封家书”；首次使用可跟随或跳过气泡引导。当前正式后端已可连接，运行状态及手机验收边界见发布记录。

静态检查：

```powershell
pnpm --filter @warm-letter/miniprogram typecheck
```

## 功能验收路径

生产界面不提供一键演示素材入口。使用本人有权使用的素材验收；可先走纯文字流程，再单独验证图片和录音：

1. 点“写一封家书”，在“直接写下一点近况”填写内容并点“加入这段文字”；图片或录音由用户主动添加。
2. 生成草稿，展示“AI 辅助生成”和每段“内容依据”。
3. 修改一段正文，在“预览并寄出”页查看完整家书，或使用“换一版文字”。
4. 选择音色生成并试听 AI 家书朗读，确认后点“选择微信好友寄出”。
5. 从实际生成的分享进入收信页，播放已生成的 AI 朗读、切换“大字/特大”字号、查看素材来源；发送回复需要微信登录。
6. 首页“隐私与数据管理”可查看服务端家书列表、删除单封家书或注销并删除全部数据。删除会撤销相关分享链接，不会删除手机原文件或微信账号。

生成和内容审核耗时受网络、素材及外部服务影响，不承诺固定完成时间。图片/录音审核可能异步返回；待审核时保留草稿并阻止分享。模拟器测试不能代替真实手机的授权、登录、录音和分享验收。

当前真实 API 适配器按 `presign -> uploadBinary -> complete` 流程上传照片、截图和语音，
并通过公开 reader 返回的媒体地址预览或播放。寄出前预览页可调用服务端 Qwen
`qwen3-tts-flash` 生成家书朗读；音频与确认稿绑定，分享后仍通过短期媒体凭据读取，并明确
标注为 AI 合成声音。`presign` 与 `complete` 使用暖笺 API Bearer
鉴权；外部上传 PUT 只转发 `presign` 返回的 headers，不得携带登录 `Authorization` 或
Cookie。Demo 素材与微信临时媒体路径不得作为真实用户素材、真实 AI 调用或生产证据。

微信不允许小程序读取好友列表。页面中的“选择微信好友寄出”使用 `open-type="share"`
调起微信原生转发面板，具体好友完全由用户选择。体验版只能由管理员和已添加的体验成员
打开；普通微信好友访问需要先通过微信审核并正式发布。
