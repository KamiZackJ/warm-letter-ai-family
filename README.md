## 作品概述

“暖笺·AI家书”是一款以微信小程序为主要载体、以 H5 分享页为补充的 AI 家书创作工具。用户可主动选择照片、聊天截图、语音、日程信息和一天的文字总结，由 AI 在用户确认和可追溯素材依据下生成可编辑的家书，并支持动态家书、手书风格长图和短片等输出形态。

作品强调生活化使用、隐私边界和可核验生成：不直接读取微信聊天记录，不扫描完整相册，不克隆亲友声音，所有素材由用户主动上传并可删除。
